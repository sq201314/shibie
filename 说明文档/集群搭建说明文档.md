### 1.2 协同训练原理

```
一个模型的参数（权重）= 在两张卡上各保存一份完整副本

           ┌─────────────┐
           │  全局 Batch  │  比如 12 张图片
           └──────┬──────┘
                  │ 切分
            ┌─────┴─────┐
            ▼           ▼
       ┌─────────┐ ┌─────────┐
       │ GPU 0   │ │ GPU 1   │
       │ 6 张    │ │ 6 张    │
       │         │ │         │
       │ 完整模型│ │ 完整模型│
       │ 前向传播│ │ 前向传播│
       │ 反向传播│ │ 反向传播│
       └────┬────┘ └────┬────┘
            │           │
            ▼           ▼
          梯度0       梯度1
            │           │
            └─────┬─────┘
                  ▼
            AllReduce 同步
           (所有梯度取平均)
                  │
                  ▼
            两份模型参数
            同时更新 → 保持一致
```

**一句话总结**：每张卡用不同的数据子集做前向+反向，然后 AllReduce 平均梯度，两份模型始终同步。

## 3. SSH 免密互信

**目标**：任何一台机器可以无密码 SSH 到另一台。

### 3.1 两台机器上创建同一个用户（如果已有则跳过）

```bash
# 两台都做，确保用户名相同
sudo adduser gpucluster
sudo usermod -aG sudo gpucluster
```

> 后续所有操作都以 `gpucluster` 用户进行。实际环境中用户名为 `a`。

### 3.2 在 node1 上生成密钥

```bash
ssh-keygen -t ed25519 -C "cluster-key"
# 一路回车，不设密码
```

### 3.3 把公钥分发到所有节点（包括自己）

```bash
ssh-copy-id a@node1
ssh-copy-id a@node2
```

每台都要输入一次密码。

### 3.4 在 node2 上也做同样的事

```bash
ssh-keygen -t ed25519 -C "cluster-key" -N ""
ssh-copy-id a@node1
ssh-copy-id a@node2
```

### 3.5 验证免密登录

```bash
# 从 node1
ssh a@node2 "hostname && whoami"
# 应该输出: node2 / a（不需要密码）

# 从 node2
ssh a@node1 "hostname && whoami"
# 应该输出: node1 / a（不需要密码）
```

EOF

source ~/.bashrc
```

## 6. 共享 conda 环境 + PyTorch

> 将环境创建在 NFS 共享路径下，两台机器都能使用。

### 6.1 安装 Miniconda（两台都做）

```bash

wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh -b -p $HOME/miniconda3

eval "$($HOME/miniconda3/bin/conda shell.bash hook)"
conda init bash
source ~/.bashrc
```

验证：

```bash
conda --version
```

### 6.2 在共享路径上创建训练环境（只需在 node1 上做一次）

> 环境装到 `/data/shared/envs/train`，NFS 共享后两台都能用。

```bash
# 创建环境
conda create --prefix /data/shared/envs/train python=3.10 -y
conda activate /data/shared/envs/train

# 安装 PyTorch（CUDA 12.6 版本）
# 注意：torchaudio 目前没有 cu126 的 wheel，做视觉训练不需要它，跳过即可
pip install torch torchvision \
  --index-url https://download.pytorch.org/whl/cu126

# 安装常用库
pip install ultralytics timm transformers opencv-python-headless \
  tqdm matplotlib scipy einops
```

### 6.3 验证 PyTorch + CUDA（两台都验证）

```bash
# node1
python3 -c "
import torch
print(f'PyTorch: {torch.__version__}')
print(f'CUDA: {torch.cuda.is_available()}')

## 7. NFS 共享存储

**目的**：让两台机器看到同一份数据和代码，不用复制两份。

### 7.1 Master（node1）上 — 安装 NFS Server

```bash
sudo apt install -y nfs-kernel-server

# 创建共享目录
sudo mkdir -p /data/shared/{datasets,checkpoints,code,logs,configs,envs}
sudo chown -R a:a /data/shared
chmod -R 775 /data/shared
```

### 7.2 Master（node1）上 — 配置导出

```bash
echo '/data/shared 192.168.1.0/24(rw,sync,no_subtree_check,no_root_squash)' | \
  sudo tee /etc/exports

sudo exportfs -ra
sudo systemctl restart nfs-kernel-server
sudo systemctl enable nfs-kernel-server
```

验证导出：

```bash
sudo exportfs -v
# 应该看到 /data/shared 导出信息
```

### 7.3 Worker（node2）上 — 安装 NFS Client 并挂载

```bash
sudo apt install -y nfs-common

sudo mkdir -p /data/shared
sudo mount node1:/data/shared /data/shared

# 验证
ls /data/shared/
# 应该看到 datasets checkpoints code logs configs envs
df -h /data/shared
```

### 7.4 设置开机自动挂载

```bash
echo 'node1:/data/shared /data/shared nfs defaults,_netdev 0 0' | \
  sudo tee -a /etc/fstab

# 测试 fstab 是否正确
sudo umount /data/shared
sudo mount -a
ls /data/shared/
```

# ===== NCCL 分布式通信配置 =====

source ~/.bashrc
```

```bash

net.core.wmem_max = 16777216
net.core.rmem_default = 16777216

## 9. 环境全面验证

### 9.1 创建验证脚本

```bash
cat > /data/shared/code/cluster-test/verify_all.py << 'PYEOF'
#!/usr/bin/env python3
"""集群环境验证脚本 — 两台机器同时运行"""
import os
import sys
import socket

def section(title):
    print(f"\n{'='*50}")
    print(f"  {title}")
    print(f"{'='*50}")

def check(name, fn):
    try:
        result = fn()
        print(f"  [✓] {name}: {result}")
        return True
    except Exception as e:
        print(f"  [✗] {name}: {e}")
        return False

section("主机信息")
print(f"  主机名: {socket.gethostname()}")

section("Python 环境")
check("Python 版本", lambda: sys.version.split()[0])

section("PyTorch & CUDA")
import torch
check("PyTorch", lambda: torch.__version__)
check("CUDA available", lambda: torch.cuda.is_available())
check("CUDA 版本", lambda: torch.version.cuda)
check("GPU 名称", lambda: torch.cuda.get_device_name(0))
check("GPU 显存", lambda: f"{torch.cuda.get_device_properties(0).total_memory / 1024**3:.1f} GB")
check("NCCL 版本", lambda: str(torch.cuda.nccl.version()))

section("GPU 算力测试")
def gpu_test():
    x = torch.randn(4096, 4096, device='cuda')
    import time
    start = time.time()
    for _ in range(50):
        torch.mm(x, x)
    torch.cuda.synchronize()
    elapsed = time.time() - start
    return f"{elapsed:.2f}s (50次 4096x4096 矩阵乘法)"
check("GPU 计算", gpu_test)

section("NFS 共享存储")
def nfs_test():
    test_file = "/data/shared/.nfs_test"
    with open(test_file, "w") as f:
        f.write(socket.gethostname())
    with open(test_file, "r") as f:
        content = f.read()
    os.remove(test_file)
    return f"读写正常 (写入: {content})"
check("NFS 读写", nfs_test)

section("常用 Python 库")
for lib_name in ["ultralytics", "timm", "transformers", "cv2"]:
    def check_lib(name=lib_name):
        __import__(name)
        return "已安装"
    check(lib_name, check_lib)

print(f"\n{'='*50}")
print(f"  验证完成 — {socket.gethostname()}")
print(f"{'='*50}")
PYEOF

## 10. 分布式训练脚本

### 10.1 完整脚本：`train_yolo11m_distributed.py`

> 此脚本经过多次调试，解决了 Ultralytics 8.4.x 版本的分布式兼容问题。

```bash
cat > /data/shared/code/vision-train/train_yolo11m_distributed.py << 'PYEOF'
#!/usr/bin/env python3
# ============================================================================
# YOLO11m 12类目标检测 — 双机分布式训练 (RTX 3060 12GB × 2)
# 首次训练 + 可靠断点续训 + 6000 epoch
# 启动方式:
#   torchrun --nnodes=2 --nproc_per_node=1 \
#     --rdzv_id=yolo11m_6000 --rdzv_backend=c10d \

MASTER_ADDR = os.environ.get("MASTER_ADDR", "node1")
MASTER_PORT = os.environ.get("MASTER_PORT", "29600")

BEST_PT     = WEIGHTS_DIR / "best.pt"

GB = 1024 ** 3

# ============================================================================
# 工具函数
# ============================================================================
def log(msg: str) -> None:
    if IS_MAIN:
        print(msg, flush=True)


def section(title: str) -> None:
    log(f"\n{'=' * 100}")
    log(f"  {title}")
    log(f"{'=' * 100}")


def load_ckpt(path: Path) -> dict[str, Any]:
    try:
        return torch.load(path, map_location="cpu", weights_only=False)
    except TypeError:
        return torch.load(path, map_location="cpu")


def atomic_save(obj: Any, path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_suffix(".tmp")
    torch.save(obj, tmp)
    os.replace(tmp, path)


def count_images(directory: Path) -> int:
    return sum(1 for p in directory.rglob("*") if p.is_file() and p.suffix.lower() in IMAGE_EXTENSIONS)


def as_dict(v: Any) -> dict:
    if isinstance(v, dict):
        return v
    if hasattr(v, "__dict__"):
        return vars(v)
    return {}


# ============================================================================
# NCCL 初始化 / 清理
# ============================================================================
def setup_distributed() -> None:
    """初始化 NCCL 进程组（必须在 Ultralytics 训练之前调用）"""
    if not dist.is_initialized():
        dist.init_process_group(backend="nccl", init_method="env://")
    torch.cuda.set_device(LOCAL_RANK)


def cleanup_distributed() -> None:
    if dist.is_initialized():
        try:
            dist.barrier()
        except Exception:
            pass
        dist.destroy_process_group()

def check_dataset() -> dict[str, int]:
    section("检查数据集")

    required = {
        "data.yaml": DATA_YAML,
        "train/images": TRAIN_IMAGES,
        "valid/images": VAL_IMAGES,
        "test/images": TEST_IMAGES,
    }

    for name, path in required.items():
        if not path.exists():
            raise FileNotFoundError(f"缺少 {name}: {path}")
        log(f"  {name:14s}: {path}")

    counts = {
        "train": count_images(TRAIN_IMAGES),
        "valid": count_images(VAL_IMAGES),
        "test":  count_images(TEST_IMAGES),
    }

    log("\n  图片数量:")
    for split, cnt in counts.items():
        log(f"    {split:5s}: {cnt}")

    if counts["train"] == 0:
        raise RuntimeError("train/images 为空")
    if counts["valid"] == 0:
        raise RuntimeError("valid/images 为空")

    return counts


# ============================================================================
# 进度读取
# ============================================================================
def read_csv_epoch() -> int | None:
    """从 results.csv 读取最后完成的 epoch"""
    if not RESULTS_CSV.exists():
        return None
    try:
        with RESULTS_CSV.open("r", encoding="utf-8-sig") as f:
            reader = csv.DictReader(f)
            last_epoch = None
            for row in reader:
                for k, v in row.items():
                    if "epoch" in k.strip().lower() and v.strip():
                        try:
                            last_epoch = int(float(v))
                        except ValueError:
                            pass
            return last_epoch
    except Exception:
        return None


def read_ckpt_epoch(ckpt: dict) -> int | None:
    """从 checkpoint 读取已完成 epoch"""
    epoch = ckpt.get("epoch")
    if epoch is None:
        return None
    try:
        e = int(epoch)
        return e + 1 if e >= 0 else None
    except (TypeError, ValueError):
        return None


def get_completed_epochs(ckpt: dict | None = None) -> int | None:
    """综合 checkpoint 和 csv 判断已完成 epoch"""
    candidates = []
    if ckpt is not None:
        ce = read_ckpt_epoch(ckpt)
        if ce is not None:
            candidates.append(ce)
    csv_e = read_csv_epoch()
    if csv_e is not None:
        candidates.append(csv_e)
    return max(candidates) if candidates else None


# ============================================================================
# 检查训练状态
# ============================================================================
def check_training_status() -> tuple[str, dict | None]:
    """
    返回: ("new" | "resume" | "done", checkpoint_or_None)
    """
    section("检查训练状态")
    log(f"  实验目录 : {RUN_DIR}")
    log(f"  last.pt  : {LAST_PT}  {'存在' if LAST_PT.exists() else '不存在'}")
    log(f"  best.pt  : {BEST_PT}  {'存在' if BEST_PT.exists() else '不存在'}")

    if not LAST_PT.exists():
        log("\n  → 判定：首次训练（last.pt 不存在）")
        return "new", None

    ckpt = load_ckpt(LAST_PT)
    if not isinstance(ckpt, dict):
        log("\n  ⚠ last.pt 格式异常，按首次训练处理")
        return "new", None

    completed = get_completed_epochs(ckpt)
    has_optimizer = ckpt.get("optimizer") is not None

    log(f"\n  Checkpoint 状态:")
    log(f"    epoch 字段    : {ckpt.get('epoch')}")
    log(f"    已完成 epoch  : {completed}")
    log(f"    optimizer     : {'存在' if has_optimizer else '不存在'}")
    log(f"    best_fitness  : {ckpt.get('best_fitness')}")

    if completed is not None and completed >= TARGET_EPOCHS:
        log(f"\n  → 判定：训练已完成（{completed} >= {TARGET_EPOCHS}）")
        return "done", ckpt

    if has_optimizer and completed is not None and completed > 0:
        log(f"\n  → 判定：断点续训（从 epoch {completed} 继续）")
        return "resume", ckpt

    # last.pt 存在但没有 optimizer（可能被 Ultralytics strip 了）
    log("\n  ⚠ last.pt 不包含 optimizer，无法真正 resume")
    log("    将从 last.pt 权重重新开始训练（不是续训）")
    return "new", ckpt


# ============================================================================
# 准备续训 checkpoint
# ============================================================================
def prepare_resume_checkpoint(ckpt: dict) -> Path:
    """
    修改 checkpoint 中的 epochs 为目标值，保存为临时文件
    Ultralytics resume 会读取 checkpoint 内的 train_args.epochs
    """
    patched = dict(ckpt)

    # 更新 train_args
    train_args = dict(as_dict(ckpt.get("train_args", {})))
    old_epochs = train_args.get("epochs", "?")
    train_args["epochs"] = TARGET_EPOCHS
    train_args["data"] = str(DATA_YAML)
    train_args["patience"] = PATIENCE
    patched["train_args"] = train_args

    # 同步更新 ema/model 的 args
    for key in ("ema", "model"):
        obj = patched.get(key)
        if obj is not None and hasattr(obj, "args"):
            try:
                m_args = dict(as_dict(obj.args))
                m_args["epochs"] = TARGET_EPOCHS
                m_args["data"] = str(DATA_YAML)
                m_args["patience"] = PATIENCE
                obj.args = m_args
            except Exception:
                pass

    atomic_save(patched, RESUME_PT)

    completed = get_completed_epochs(ckpt)
    log(f"  原 epochs : {old_epochs}")
    log(f"  新 epochs : {TARGET_EPOCHS}")
    log(f"  已完成   : {completed}")
    log(f"  剩余     : {TARGET_EPOCHS - (completed or 0)}")
    log(f"  临时文件 : {RESUME_PT}")

    # 同步所有 rank
    if WORLD_SIZE > 1 and dist.is_initialized():
        dist.barrier()

    return RESUME_PT

# 首次训练
# ============================================================================
def train_new() -> None:
    section("首次训练（双机分布式）")

    global_batch = BATCH * WORLD_SIZE
    log(f"  预训练模型 : {PRETRAINED_MODEL}")
    log(f"  数据集     : {DATA_YAML}")
    log(f"  总 Epoch   : {TARGET_EPOCHS}")
    log(f"  图像尺寸   : {IMGSZ}")
    log(f"  Batch/卡   : {BATCH}")
    log(f"  全局 Batch : {global_batch}")
    log(f"  学习率     : {LR0} (×{WORLD_SIZE} 线性缩放)")
    log(f"  节点数     : {WORLD_SIZE}")
    log(f"  训练目录   : {RUN_DIR}")

    RUN_DIR.mkdir(parents=True, exist_ok=True)
    torch.cuda.empty_cache()

    model = YOLO(PRETRAINED_MODEL)
    model.train(
        data=str(DATA_YAML),
        epochs=TARGET_EPOCHS,
        imgsz=IMGSZ,
        batch=BATCH,
        device=f"cuda:{LOCAL_RANK}",
        workers=WORKERS,
        project=str(RUN_DIR.parent),
        name=RUN_DIR.name,
        exist_ok=True,
        save=True,
        save_period=SAVE_PERIOD,
        patience=PATIENCE,
        close_mosaic=CLOSE_MOSAIC,
        seed=SEED,
        deterministic=False,
        pretrained=True,
        amp=True,
        plots=False,
        verbose=IS_MAIN,
        lr0=LR0,
    )


# ============================================================================
# 断点续训
# ============================================================================
def train_resume(ckpt: dict) -> None:
    section("断点续训（双机分布式）")

    resume_path = prepare_resume_checkpoint(ckpt)

    log(f"  Batch/卡   : {BATCH}")
    log(f"  全局 Batch : {BATCH * WORLD_SIZE}")
    log(f"  节点数     : {WORLD_SIZE}")
    log(f"  EarlyStop  : 关闭")

    torch.cuda.empty_cache()

    model = YOLO(str(resume_path))
    model.train(
        resume=True,
        imgsz=IMGSZ,
        batch=BATCH,
        device=f"cuda:{LOCAL_RANK}",
        workers=WORKERS,
        save_period=SAVE_PERIOD,
        patience=PATIENCE,
        close_mosaic=CLOSE_MOSAIC,
        plots=False,
        verbose=IS_MAIN,
    )

    # 清理临时文件（仅 rank0）
    if IS_MAIN and RESUME_PT.exists():
        RESUME_PT.unlink(missing_ok=True)


# ============================================================================
# 最终验证（仅 rank0）
# ============================================================================
def evaluate() -> None:
    if not IS_MAIN:
        if dist.is_initialized():
            dist.barrier()
        return

    section("最终验证")

    if BEST_PT.exists():
        model_path = BEST_PT
        log("  使用 best.pt")
    elif LAST_PT.exists():
        model_path = LAST_PT
        log("  best.pt 不存在，使用 last.pt")
    else:
        log("  没有找到模型文件，跳过验证")
        if dist.is_initialized():
            dist.barrier()
        return

    log(f"  模型: {model_path}")

    torch.cuda.empty_cache()
    model = YOLO(str(model_path))
    metrics = model.val(
        data=str(DATA_YAML),
        imgsz=IMGSZ,
        batch=BATCH,
        device=f"cuda:{LOCAL_RANK}",
        plots=True,
        verbose=True,
    )

    mp    = float(metrics.box.mp)
    mr    = float(metrics.box.mr)
    map50 = float(metrics.box.map50)
    map95 = float(metrics.box.map)

    section("验证结果")
    log(f"  Precision  : {mp:.4f} ({mp*100:.2f}%)")
    log(f"  Recall     : {mr:.4f} ({mr*100:.2f}%)")
    log(f"  mAP50      : {map50:.4f} ({map50*100:.2f}%)")
    log(f"  mAP50-95   : {map95:.4f} ({map95*100:.2f}%)")

    log("\n  各类别 AP50:")
    try:
        names = model.names
        for i, ap in enumerate(metrics.box.ap50):
            name = names.get(i, str(i)) if isinstance(names, dict) else names[i]
            log(f"    {str(name):>20s}: {float(ap)*100:7.2f}%")
    except Exception as exc:
        log(f"    ⚠ 无法输出: {exc}")

    if dist.is_initialized():
        dist.barrier()

def save_summary(counts: dict[str, int]) -> None:
    if not IS_MAIN:
        return

    import json

    summary = {
        "timestamp": time.strftime("%Y-%m-%d %H:%M:%S"),
        "model": PRETRAINED_MODEL,
        "target_epochs": TARGET_EPOCHS,
        "imgsz": IMGSZ,
        "batch_per_gpu": BATCH,
        "global_batch": BATCH * WORLD_SIZE,
        "world_size": WORLD_SIZE,
        "lr0": LR0,
        "dataset": {
            "train": counts.get("train", 0),
            "valid": counts.get("valid", 0),
            "test": counts.get("test", 0),
        },
        "paths": {
            "run_dir": str(RUN_DIR),
            "best_pt": str(BEST_PT),
            "last_pt": str(LAST_PT),
            "data_yaml": str(DATA_YAML),
        },
    }

    summary_path = RUN_DIR / "training_summary.json"
    RUN_DIR.mkdir(parents=True, exist_ok=True)
    with summary_path.open("w") as f:
        json.dump(summary, f, indent=2, ensure_ascii=False)
    log(f"  摘要保存: {summary_path}")


# ============================================================================
# 主入口
# ============================================================================
def main() -> None:
    setup_distributed()

    try:
        start_time = time.time()

        # 1. 环境检查
        check_environment()

        # 2. 数据集检查
        counts = check_dataset()

        # 3. 判断训练状态
        status, ckpt = check_training_status()

        # 4. 执行
        if status == "done":
            log("\n训练目标已达成，直接验证。")
        elif status == "resume":
            train_resume(ckpt)
        else:
            train_new()

        # 5. 验证
        evaluate()

        # 6. 摘要
        save_summary(counts)

        # 7. 完成
        elapsed_h = (time.time() - start_time) / 3600
        section(f"全部完成（耗时 {elapsed_h:.2f} 小时）")
        log(f"  实验目录 : {RUN_DIR}")
        log(f"  Best     : {BEST_PT}")
        log(f"  Last     : {LAST_PT}")

    except KeyboardInterrupt:
        log("\n用户中断。下次运行自动续训。")
        sys.exit(130)

    except Exception as exc:
        section("训练错误")
        log(f"  {type(exc).__name__}: {exc}")
        raise

    finally:
        cleanup_distributed()


if __name__ == "__main__":
    main()

## 12. 踩坑记录与解决方案

### 12.1 `'rank' is not a valid YOLO argument`

**错误信息**：

```
SyntaxError: 'rank' is not a valid YOLO argument.
'world_size' is not a valid YOLO argument.
```

**原因**：Ultralytics 8.4.x 不再接受 `rank` 和 `world_size` 作为 `model.train()` 参数。

**解决**：从 `model.train()` 调用中删除这两个参数，Ultralytics 通过环境变量 `RANK` 和 `WORLD_SIZE` 自动获取。

### 12.2 `Default process group has not been initialized`

**错误信息**：

```
ValueError: Default process group has not been initialized,
please make sure to call init_process_group.
```

**原因**：Ultralytics 看到 `RANK` 和 `LOCAL_RANK` 环境变量就认为是分布式模式，内部会调用 `DistributedSampler`，但不会自动初始化 NCCL 进程组。

**解决**：在脚本最开始（`model.train()` 之前）手动调用：

```python
import torch.distributed as dist

if not dist.is_initialized():
    dist.init_process_group(backend="nccl", init_method="env://")
torch.cuda.set_device(LOCAL_RANK)
```

### 12.3 `total_mem` AttributeError

**错误信息**：

```
AttributeError: 'torch._C._CudaDeviceProperties' object has no attribute 'total_mem'.
Did you mean: 'total_memory'?
```

**原因**：PyTorch 2.13 把 `total_mem` 改名为 `total_memory`。

**解决**：

```bash
sed -i 's/\.total_mem/\.total_memory/g' train_yolo11m_distributed.py
```

### 12.4 `torchaudio` 安装失败

**错误信息**：

```
ERROR: Could not find a version that satisfies the requirement torchaudio
```

**原因**：`torchaudio` 可能没有对应 CUDA 版本的预编译 wheel。

**解决**：做视觉训练不需要 `torchaudio`，直接跳过，只装 `torch` 和 `torchvision`。

### 12.5 错误信息被 torchrun 吞掉

**现象**：`torchrun` 只显示 `exitcode: 1`，看不到真正的 Python traceback。

**解决**：用单机模式直接运行，能看到完整报错：

```bash
WORLD_SIZE=1 RANK=0 LOCAL_RANK=0 MASTER_ADDR=node1 MASTER_PORT=29600 \
  python3 train_yolo11m_distributed.py 2>&1 | head -100
```

### 12.6 NCCL WARN lib wrapper not initialized

**日志**：

```
NCCL WARN lib wrapper not initialized.
```

**说明**：这是关于 InfiniBand 的警告，不影响 TCP 通信。因为我们设置了 `NCCL_IB_DISABLE=1`，NCCL 会走 TCP/socket 通信，完全正常。

### 13.4 常见问题速查

| 现象 | 原因 | 解决 |
|------|------|------|
| `nvidia-smi` 报错 | 驱动没装好 | `sudo apt install --reinstall nvidia-driver-535` |
| `nvcc --version` 找不到 | PATH 没配置 | `source ~/.bashrc` 或检查 CUDA_HOME |
| `torch.cuda.is_available()` 为 False | PyTorch 和 CUDA 版本不匹配 | 重装 PyTorch |
| NFS 挂载失败 | NFS server 没启动 | `sudo systemctl restart nfs-kernel-server` |
| 训练卡在初始化不跑 | 两台没同时启动 | 确保 ssh 命令都在执行，检查 `MASTER_ADDR` |
| 训练速度两台比一台还慢 | 千兆网带宽不够 | 升级万兆网卡+交换机 |
| `RuntimeError: Address already in use` | 端口冲突 | 换端口 `--master_port 29501` |
| SSH 超时训练中断 | 用 tmux 包裹 | `tmux new -s train` 再运行 |

## 14. 附录：原理说明

### 14.1 DDP（Distributed Data Parallel）原理

```
┌────────────────────────────────────────────────────────┐
│                       DDP                               │
│                                                         │
│  GPU 0          GPU 1                                   │
│  ┌────────┐    ┌────────┐                               │
│  │模型参数│    │模型参数│  ← 每卡完整副本               │
│  │优化器  │    │优化器  │  ← 每卡完整副本               │
│  │梯度    │    │梯度    │  ← 每卡完整副本               │
│  └────────┘    └────────┘                               │
│                                                         │
│  GPU 0 用 batch 0-5 做前向+反向                         │
│  GPU 1 用 batch 6-11 做前向+反向                        │
│  AllReduce 同步梯度                                     │
│  两份参数同时更新                                       │
└────────────────────────────────────────────────────────┘
```

### 14.2 为什么不是 2× 加速？

```
单机单卡:    ~350 img/s   基准线
双机双卡DDP: ~650 img/s   加速比 ~1.86x

为什么不是 2.0x？
├── 网络通信开销 (AllReduce 同步梯度)  → 损耗 10-15%
├── 每卡数据量相同但数据量增大后通信量也增大
└── 千兆网 vs 万兆网差距巨大

千兆网 (1Gbps):  加速比约 1.5-1.8x
万兆网 (10Gbps): 加速比约 1.8-1.95x
```

### 14.3 显存预算（RTX 3060 12GB）

| 用途 | 占用 |
|------|------|
| YOLO11m 模型参数 | ~2 GB |
| 优化器状态 (SGD) | ~2 GB |
| 梯度 | ~2 GB |
| 激活值 (batch=6, imgsz=1024) | ~4-5 GB |
| 临时缓冲 | ~1 GB |
| **总计** | **~11-12 GB**（接近满载） |

> 如果出现 CUDA OOM，减小 `BATCH`（从 6 改为 4 或 2）或减小 `IMGSZ`（从 1024 改为 640）。

### 14.4 模型大小与方案选择

```
模型能在单卡 12GB 跑？
├── 能 → 用 DDP（数据并行）  ← 本方案
│         双卡速度 ≈ 1.5-1.9x
│         最简单，最常用
│
└── 不能 → 用 DeepSpeed ZeRO Stage 2/3
            把优化器状态/梯度分摊到多卡
```
